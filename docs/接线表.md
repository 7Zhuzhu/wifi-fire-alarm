# 接线表

主控：STC89C52RC，晶振 **11.0592MHz**（串口通信必须用这个频率才不丢波特率），5V 供电。

## 1. 最小系统

| 单片机引脚 | 接到 | 说明 |
|---|---|---|
| XTAL1 / XTAL2 | 11.0592MHz 晶振 | 各配 30pF 电容到 GND |
| RST | 复位电路 | 10μF + 10kΩ + 按键 |
| EA | 5V | 使用片内 ROM |
| VCC / GND | 5V / GND | 就近 0.1μF 去耦 |
| P0.0~P0.7 | 10kΩ 排阻 → 5V | P0 开漏，必须上拉 |

## 2. LCD1602

| LCD 引脚 | 接到 | 说明 |
|---|---|---|
| VSS | GND | — |
| VDD | 5V | — |
| V0（对比度） | 10kΩ 电位器中间脚 | 调不出字先调这里 |
| RS | P2.5 | 数据/指令选择 |
| RW | P2.6 | 读写选择（本工程只写，可接地） |
| E | P2.7 | 使能，下降沿锁存 |
| D0~D7 | P0.0~P0.7 | 8 位并行 |
| A / K（背光） | 5V / 串 100Ω → GND | 不串电阻会烧背光 |

## 3. 温度与烟雾

| 器件 | 引脚 | 接到 | 说明 |
|---|---|---|---|
| DS18B20 | VDD / GND / DQ | 5V / GND / **P1.5** | DQ 需 4.7kΩ 上拉到 5V |
| MQ-2 | VCC / GND / AO | 5V / GND / ADC0832 CH0 | 上电预热 2~3 分钟 |
| ADC0832 | CS / CLK / DI/DO | **P2.3 / P2.0 / P2.1** | 软件模拟 SPI |
| ADC0832 | VCC / GND | 5V / GND | — |

## 4. ESP8266（关键，最容易接错）

| ESP8266 | 接到 | 说明 |
|---|---|---|
| VCC | **3.3V 独立电源** | 峰值电流 300mA，用单片机 5V 经 AMS1117 供电常常带不动 |
| GND | GND | **必须与单片机共地** |
| TXD | P3.0（单片机 RXD） | 交叉连接 |
| RXD | P3.1（单片机 TXD） | 单片机 5V 电平直连有风险，稳妥做法串 1kΩ 分压或加电平转换 |
| CH_PD（EN） | 3.3V | **不拉高模块完全不工作**，10kΩ 上拉 |
| RST | 悬空或 3.3V | — |

> 现象对照：模块灯不亮 → 供电；灯常亮不闪 → CH_PD 没拉高；AT 无回应 → 波特率不对（出厂多为 115200，需先 `AT+UART=9600,8,1,0,0`）。

## 5. 按键与报警

| 功能 | 引脚 | 说明 |
|---|---|---|
| 设置键 | P1.0 | 进入阈值设置 |
| 加键 | P1.1 | — |
| 减键 | P1.2 | — |
| 手动报警键 | P1.3 | — |
| 蜂鸣器 | P3.6 | S8050 驱动，基极 1kΩ |
| 温度灯（黄） | P1.6 | 串 1kΩ |
| 烟雾灯（红） | P1.7 | 串 1kΩ |

## 6. 上电顺序（很重要）

1. 先接 5V 主电源，确认单片机与 LCD 正常显示
2. 再接 3.3V 给 ESP8266（不要和单片机同时上电，避免浪涌把单片机拉复位）
3. 等 3~5 秒，等模块连上热点
4. 最后接传感器（MQ-2 需要预热）

顺序错了会出现「单片机动不动重启」的假故障，其实是大电流把 5V 拉塌了。
