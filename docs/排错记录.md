# 排错记录

这个项目比上一个多了一个「会联网」的变量，故障点从"电路"扩到"电路 + 网络 + 协议"。下面每一条都是实际遇到过的。

---

## 1. ESP8266 完全不回应 AT 指令

- **现象**：串口助手发 `AT`，没有任何返回。
- **逐项排查**：
  1. 模块电源灯不亮 → 量 VCC，只有 1.8V，**5V 经 AMS1117 供电带不动峰值电流**
  2. 换独立 3.3V 电源后灯亮，仍不回应 → 量 CH_PD 为 0V
  3. CH_PD 接 3.3V（10kΩ 上拉）后，`AT` 返回 `OK`
- **实际原因**：供电不足 + CH_PD 未拉高，两个问题叠在一起
- **经验**：ESP8266 必须先保证「灯亮、CH_PD 高」，再谈波特率。顺序反了会白折腾半天

## 2. 手机端看到的数据偶尔乱码

- **现象**：大部分帧正常，偶尔出现 `123 33.5` 后面跟几个乱字符。
- **定位过程**：
  1. 串口抓包，发现乱码帧长度仍是 20 字节，但后 3 位每次不一样
  2. 翻代码：`AT+CIPSEND=20`，循环 `for(i=0;i<20;i++) SendASC(da[i])`
  3. 再看缓冲区：`uchar send[16]` —— **只声明了 16 字节，却读了 20 字节**
- **实际原因**：越界读取，把缓冲区后面 RAM 里的其它变量当成数据发出去了
- **处理**：帧长统一为 17 字节，`AT+CIPSEND=17`，循环到 17；缓冲区扩到 18
- **经验**：C51 不做越界检查，数组开小了不报错，只在运行期表现为"偶发乱码"。**看到偶发脏数据先查数组边界**

## 3. LCD1602 上电只显示一排黑方块

- **现象**：通电后第一行全是实心方块，第二行空白。
- **可能原因**：①初始化时序不对 ②对比度没调 ③RW 接错
- **处理**：
  1. 先调 V0 电位器，方块变淡 → 说明屏是好的，问题在初始化
  2. 对照手册补上「上电延时 >15ms → 发 0x38 三次 → 0x0C → 0x06 → 0x01」
  3. 补完初始化后正常显示
- **经验**：1602 的初始化必须严格按手册的顺序和间隔，少一步就白屏

## 4. 改了阈值，重启又变回去

- **现象**：按键设到 33℃，断电再上电回到 50℃。
- **实际原因**：只改了 RAM 变量，没有调 `write_eeprom()`
- **处理**：设置完成（含 30 秒自动退出）时统一写一次 EEPROM；上电时用标志位判断是否首次上电，首次才写默认值
- **经验**：**每次"改参数"都要问一句：这个值掉电还在吗**

## 5. 一开 WiFi，单片机就复位

- **现象**：ESP8266 一连热点，单片机跟着重启，LCD 闪一下重新初始化。
- **实际原因**：模块发射瞬间电流冲到 300mA，5V 电源被拉塌，单片机掉到复位电压以下
- **处理**：
  1. 模块单独 3.3V 供电，与单片机电源分开走线，只在 GND 处单点共地
  2. 模块 VCC 就近并 100μF + 0.1μF 电容
  3. 上电顺序改为：先单片机，延时 3 秒再给模块上电
- **经验**：无线模块的浪涌是"看不见的复位源"，症状很像程序跑飞，其实是电源问题

## 6. MQ-2 上电 2 分钟内一直报警

- **现象**：每次上电都报烟雾，等几分钟自己好了。
- **处理**：上电后延时 2~3 分钟再进入采集与判断；采集值做中位值平均滤波
- **经验**：气敏传感器需要预热，这是器件特性。现场部署时要告诉用户"上电后请等 3 分钟"

## 7. 烧录成功但程序不跑

- **现象**：STC-ISP 显示下载成功，断电重上电没反应。
- **实际原因**：晶振用了 12MHz，而串口波特率是按 11.0592MHz 算的，通信全乱（表现为"程序像卡死"）
- **处理**：换 11.0592MHz 晶振，重新编译
- **经验**：**只要用到串口，晶振就必须是 11.0592MHz**，12MHz 的波特率误差能到 8% 以上

## 排查顺序（联网版，比纯硬件多两步）

1. **电源**：5V、3.3V 分别量，带载量
2. **时钟**：用串口就必须 11.0592MHz
3. **复位**：RST 电平、上电顺序
4. **本地功能**：先把显示、按键、报警调通，**不要一上来就联调联网**
5. **模块状态**：灯、CH_PD、AT 回应、波特率
6. **网络**：CWJAP 是否返回 OK、CIPSTATUS 是否 connected
7. **协议**：串口助手造帧，先确认字节数对，再看内容

第 4 步是最容易跳过的：本地没通就去调联网，最后分不清是传感器错还是网络错。分层的意义就是**一次只让一个变量动**。
